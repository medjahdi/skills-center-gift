> ### ⚖️ Read this first — the one rule
> Everything here is for **learning and authorized testing only**. Only ever test systems you **own** or have **written permission** to test (a bug bounty program's scope counts as permission). In Algeria, unauthorized access to a computer system is a crime under **Penal Code Article 394 bis**. The same skill builds a career or a criminal record — choose the one with a future.
